# 临床样品跨境配给

本项目用于整理临床样品跨境配给领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/clinical_supply_allocation.py`：正向链事件（释放、预测、预留、收货、既有批次隔离）与最小字段校验。
- `src/recall_contract.py`：**召回与逆向处置链**合同——带版本的召回通知、授权复核、按保管节点分派的任务、在途拦截 / 隔离确认 / 退运 / 销毁 / 替代分配 / 结果影响评估 / 结案，以及纯函数规则校验与全局看板。
- `data/sample.json`：正向链虚构事件。
- `data/recall_case.json`：一条完整的、可结案的召回逆向处置链样例（含离线回执、范围扩大、失败重试、跨时区截止）。
- `tests/`：保证样例与领域约定保持一致。

## 召回与逆向处置链约定

发起维度 `scope_level`：`lot`（批次）、`box`（箱段）、`container`（容器）、`result`（检测影响范围）。
处置动作 `action`：`intercept_in_transit`、`quarantine_confirm`、`return_to_depot`、`destroy`、`allocate_replacement`、`assess_result_impact`。

合同内置的关键约束：

- **带版本与授权闸门**：同一 `source_ref` 的通知用递增 `version` 表达修订；内容变化后必须出现针对新版本的 `RECALL_AUTHORIZATION(approved)`，否则任务与结案一律阻断。
- **幂等重放**：相同事件原样重放不产生第二组任务或凭证；相同通知重放只保留一组任务；销毁 / 退运 / 补发等终态动作的成功凭证每个任务只允许一张（重启后不会重复销毁或补发）。同一 `event_id` 内容不一致判为篡改/错投。
- **范围扩大/缩小**：扩大新增的实体（含拆分后子代）必须被覆盖；缩小不会自动解封已被**人工隔离**的实体。
- **保管权边界**：院区只能给自己保管的实体派任务；在途实体须先在途拦截并落到扣留节点后才能继续处置。
- **最小披露**：跨机构通知/任务只允许去标识研究代号，禁止姓名、证件号、病历号、生日等身份字段。
- **数量守恒与溯源**：拆分父子数量必须相等；结案数量按“销毁 + 退运 + 仍隔离 = 受影响”守恒；每项受影响结果都要能追到原批次、召回范围版本与检测时实际保管节点。
- **回执与截止**：离线回执须补 `recorded_at_utc`；失败回执须标 `retryable`，并由更高 `attempt` 闭环；截止期限必须带时区并按 UTC 比较；替代品须提供未过期效期。
- **结案不可强关**：任何未回执、数量差异、版本不符、溯源缺失都显眼列出，`force` 标记直接判违规。

`recall_dashboard(events)` 供中心质量员查看全局：现行/授权版本、各任务最新状态（含离线、失败、未回执）、结案数量差异与未决违规；院区视图应再按本节点保管的实体过滤。

# 临床样品跨境配给

本项目用于整理临床样品跨境配给领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/clinical_supply_allocation.py`：基础事件种类与最小字段校验。
- `src/recall_reverse_disposition.py`：召回与逆向处置链的事件词汇、校验与折叠规则。
- `data/sample.json`：用于核对基础资料格式的虚构事件。
- `data/recall_case.json`：用于核对召回链资料格式的虚构案例日志。
- `tests/`：保证样例与领域约定保持一致。

## 召回与逆向处置链

批次污染通知到达时，样品可能仍在库内、运输途中、已拆分给多个试验，或只剩衍生检测结果。召回链在基础合同之上扩展出以下约定，回答应该冻结什么、谁已收到通知、哪些结论需要重新解释。

### 事件种类

| 事件 | 含义 |
| --- | --- |
| `CONTAMINATION_NOTICE_RECEIVED` | 批次污染通知到达（含来源版本号与内容摘要） |
| `RECALL_ACTION_OPENED` | 按批次、箱段、容器或检测影响范围发起带版本的召回行动 |
| `RECALL_SCOPE_REVISED` | 范围修订：扩大纳入新增对象；缩小不自动解封人工隔离 |
| `RECALL_REVIEW_RESOLVED` | 同源内容变化的授权复核结论（范围不变） |
| `DISPOSITION_TASK_ISSUED` / `ACKED` / `COMPLETED` / `FAILED` | 处置任务的下发、回执、完成与部分失败 |
| `MANUAL_HOLD_PLACED` / `MANUAL_HOLD_RELEASED` | 人工隔离与显式解封 |
| `REPLACEMENT_ALLOCATED` | 替代分配完成（替代品须未过期且不在召回范围） |
| `RESULT_IMPACT_ASSESSED` | 结果影响评估完成 |
| `QUANTITY_DISCREPANCY_RESOLVED` | 数量差异的授权说明（差异记录仍保留） |
| `RECALL_CLOSURE_REQUESTED` | 结案申请；存在阻塞原因时结案失败并显眼记录 |

### 处置任务

在途拦截、隔离确认、退运、销毁、替代分配与结果影响评估分别推进，任务标识由通知、对象与任务种类唯一决定：相同通知重放只产生一组任务，失败重试沿用同一任务，系统重启后重放日志不会重复销毁或补发。

### 领域规则

- 相同通知重放只产生一组任务；来源相同但内容变化时进入待复核，必须经授权复核（范围修订或复核结论事件）才能继续下发任务。
- 范围扩大纳入新增对象并生成其任务组；范围缩小只取消未完成的自动任务，已经人工隔离的样品不自动解封。
- 各院区只能操作自己保管的实体；中心质量员通过守恒视图与未确认回执视图查看全局，不代为操作。
- 跨机构通知中患者标识保持最少披露，只允许假名 `subject_ref`，禁止直接标识字段。
- 所有时间戳须带时区偏移；物流离线回执须保留纸质记录时间；跨时区截止期限按实际时刻比较。
- 结案要求无待复核、无未确认回执、无数量差异；差异只能经授权说明后结案，任何未回执或数量差异保持显眼，不能被强行结案。
- 结案报告从每项受影响结果追到原批次、召回范围版本与实际保管节点。
